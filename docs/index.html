Metodología

Arquitectura modular, segura y medible

Construyo con la disciplina de un sistema de tiempo real: capas bien separadas, diseño guiado por el dominio, presupuestos explícitos de CPU y memoria, y verificación antes de publicar. La seguridad y la documentación forman parte de la arquitectura, no son un añadido.

  • Clean Architecture, SOLID y MVI aplicados del dominio a la interfaz
  • Criptografía aplicada: Argon2id, BLAKE3, mTLS, sellado RFC 3161 y auditoría
  • CI/CD, pruebas automatizadas y documentación técnica en cada entrega
  • Optimización perfilada de CPU, memoria, hilos y almacenamiento persistente

Criptografía & Sistemas Documentales SEC // ARGON2ID · BLAKE3 · MTLS Septiembre 2026

Bóveda Académica

Sistema integral de custodia documental académica en Rust: base cifrada, canal mTLS, sellado SHA-256 + BLAKE3 con RFC 3161, cola de admisión, auditoría encadenada y panel web de administración. Diseñado para operar en una sola máquina Linux, sin root ni servicios externos, con protocolo break-glass de dos factores para la administración de TI.

Rust 2021 Tokio rustls / mTLS Argon2id + BLAKE3 SQLite cifrado

Redes locales & Intranet offline OFF-GRID // SIN INTERNET Septiembre 2026

NetForge Studio

Convierte cualquier PC con Windows en un router local: levanta una red Wi-Fi propia, audita en vivo dispositivos (IP, MAC y fabricante), bloquea intrusos por MAC con reglas de firewall, comparte archivos por portal web y FTP, genera códigos QR y reparte internet de forma opcional. Un solo ejecutable, sin instalador ni servicios en la nube.

C# / .NET 4.8 Wi-Fi Direct Firewall Win32 HTTP + FTP QR propio
GitHub
Visor nativo & Imagen WIN32 // GLASSMORPHISM Octubre 2026

ARTPICST

Visor de imágenes premium para Windows en C++ y Win32: interfaz acrílica, renderizado con GDI+, WIC y stb_image, orientación EXIF automática, zoom continuo de 0.5% a 51200%, soporte para JPEG, PNG, WebP, AVIF, HEIC y RAW, y un presupuesto de memoria inferior a 80 MB.

C++20 Win32 API GDI+ / WIC stb_image Auto-updater

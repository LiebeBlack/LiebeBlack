## ◈ &nbsp; Sobre este repositorio

Este repositorio alberga el **portafolio profesional** de **Yoangel Gómez (LiebeBlack)** — un sitio estático construido desde cero, sin frameworks, diseñado con una estética oscura, editorial y HUD que refleja la precisión de la ingeniería de sistemas.

<table>
  <tr>
    <td width="50%">
      <h3>🎯 &nbsp; Enfoque principal</h3>
      <ul>
        <li><strong>Sistemas nativos</strong> — C++20, Win32, Direct3D 11, HLSL</li>
        <li><strong>Audio & DSP</strong> — Python, CustomTkinter, procesamiento en tiempo real</li>
        <li><strong>Hardware</strong> — WebUSB, Fastboot, ADB, Android AOSP</li>
        <li><strong>Arquitectura</strong> — Clean Architecture, SOLID, profiling</li>
      </ul>
    </td>
    <td width="50%">
      <h3>✦ &nbsp; Filosofía</h3>
      <p>Herramientas donde importan la <strong>latencia</strong>, el <strong>consumo de recursos</strong> y la <strong>claridad de cada capa</strong>. Menos dependencias, cero sorpresas en producción. Cada capa —de la API gráfica al protocolo USB— se elige para resolver el problema en el punto exacto donde ocurre.</p>
    </td>
  </tr>
</table>

## ◈ &nbsp; Sobre el sitio web

El portafolio está construido como un **sitio estático ligero**, sin frameworks ni dependencias de runtime:

<div align="center">

| Característica | Detalle |
|:---|:---|
| 🎨 &nbsp; **Diseño** | Responsive, estética oscura editorial con HUD táctico |
| ✨ &nbsp; **Animaciones** | Progresivas con `IntersectionObserver`, sin jank |
| 🖱️ &nbsp; **Microinteracciones** | Cursor personalizado en dispositivos compatibles |
| ♿ &nbsp; **Accesibilidad** | `prefers-reduced-motion`, ARIA labels, semántica |
| 📧 &nbsp; **Contacto** | Formulario con Formspree y adjuntos opcionales |
| 🔍 &nbsp; **SEO** | Open Graph, datos estructurados JSON-LD, precarga |
| ⚡ &nbsp; **Performance** | Prerender (Speculation Rules API), `fetchpriority`, 0 deps |

</div>

## ◈ &nbsp; Ejecutar localmente

No se requiere compilación ni instalación de dependencias. Sirve `docs/` con cualquier servidor estático:

```bash
# Python
python -m http.server 8000 --directory docs

# Node.js (npx)
npx serve docs

# VS Code
# Extensión Live Server → clic derecho en docs/index.html
```

Después abre [`http://localhost:8000`](http://localhost:8000)
